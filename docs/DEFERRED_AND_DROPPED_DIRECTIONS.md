# Deferred and Dropped Directions

The following directions are intentionally outside this public staging tree. Their exclusion preserves a narrow, reviewable software scope and does not imply that they have been completed, evaluated, or rejected on scientific grounds.

| Direction | Public-tree disposition | Rationale |
|---|---|---|
| External connectome acquisition or ingestion | Deferred | External material and its metadata are outside the data-free boundary. |
| Dataset-specific graph construction | Deferred | It would require source-specific choices and potentially derived artifacts. |
| Empirical motif counting or null-ensemble comparison | Deferred | This tree does not contain empirical inputs, outputs, or outcome claims. |
| Figures, visual specifications, and rendered assets | Dropped from this tree | Visual artifacts can encode results or provenance and are not needed for the retained utilities. |
| Archive indexes, retrieval notes, and access records | Dropped from this tree | They are internal operational material rather than public software documentation. |
| Notebook-based exploration | Dropped from this tree | Notebooks and execution state are excluded to keep the release boundary straightforward. |
| Biological, functional, or causal interpretation | Deferred | The retained utilities do not establish those interpretations. |

Future consideration of any deferred direction requires an owner decision on scope, access, documentation, and release handling before code or documentation is added.
